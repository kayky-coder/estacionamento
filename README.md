# Estacionamento

O programa visa facilitar a visualização das vagas em um estacionamento, facilitando na hora de estacionar, retirar e ver as vagas disponíveis no estacionamento. É um sistema de console em Java com a quantidade fixa de 5 vagas e que guarda os carros em um array.

## Funcionalidades

- Estacionar o carro na primeira vaga livre
- Retirar o carro pela placa
- Listar todas as vagas, mostrando as livres e as ocupadas
- Avisar quando o estacionamento está cheio
- Impedir que a mesma placa seja estacionada duas vezes
- Aceitar a placa em maiúscula ou minúscula
- Tratar entradas inválidas no menu, sem quebrar o programa

## Como executar

1. Baixe ou clone este repositório
2. Abra a pasta no VS Code
3. Execute o arquivo Main.java
